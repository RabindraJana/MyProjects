# New Year's Eve Countdown

A simple one-page countdown page for New Year's Eve with a dark neon style and live ticking timer.

## Project overview

This project is a lightweight static web page built to show the time remaining until midnight on New Year's Eve.

## Files

- `public/index.html` — main page structure, styling, and countdown logic
- `project.toml` — project metadata

## Run locally

Open the project in a browser or serve it locally from the workspace folder.

Example:

```bash
cd "c:\Users\rabin\Downloads\new-years-eve-qbot-v1"
py -m http.server 8000
```

Then visit:

```text
http://localhost:8000/public/index.html
```

## Notes

This is a personal standalone web project and is intended to be used as-is for local viewing and customization.
